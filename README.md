# expresscoupon.info

Funnel page for weekly/monthly coupons and free product offers.

## Features
- Coupon of the Week / Month with copy-to-clipboard codes
- Freebies section (Habit Journal, Audible Trial, Shadow Work Journal)
- All freebies redirect to jrb.codes
- Links to hawie.shop and racksontop.me

## Dev
```bash
npm install
npm run dev  # localhost:3140
```

## Deploy
Cloudflare Pages — build cmd: `npm run build`, output: `out`
